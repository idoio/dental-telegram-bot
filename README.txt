# Telegram-бот для стоматологической клиники

Бот для автоматизации записи пациентов на прием.

## Функции
- Многошаговая форма записи
- Проверка свободных слотов
- Сохранение в Excel с резервным копированием на Яндекс.Диск
- Уведомления администратора

## Установка
1. Клонируй репозиторий
2. Создай `.env` по примеру `.env.example`
3. Установи зависимости: `pip install -r requirements.txt`
4. Запусти: `python bot.py`

## Технологии
- Python 3.10+
- Aiogram 3.x
- OpenPyXL
- Yandex Disk API
